Manajemen Siswa
Fitur Cara pakai

Kelola data siswa langsung dari terminal.

Aplikasi CLI berbasis Python untuk mencatat, mencari, dan merekap data siswa. Tanpa server, tanpa instalasi rumit — data tersimpan otomatis ke JSON di komputer kamu sendiri.

Unduh manajemen_siswa.py Python 3 · tanpa dependensi eksternal
manajemen_siswa.py — terminal
$ python manajemen_siswa.py ============================================= APLIKASI MANAJEMEN SISWA (CRUD) ============================================= 1. Tambah Data Siswa 2. Lihat Semua Data Siswa 3. Cari Data Siswa 4. Edit Data Siswa 5. Hapus Data Siswa 6. Hitung Siswa per Kelas/Jurusan 0. Keluar ============================================= Pilih menu (0-6):

Yang bisa dilakukan

Enam menu inti, cukup lewat keyboard.

Tambah data siswa

Input NIS, nama, kelas/jurusan, jenis kelamin, dan alamat. NIS ganda otomatis ditolak.

Lihat semua siswa

Menampilkan seluruh data dalam tabel rapi langsung di terminal.

Cari siswa

Pencarian cepat berdasarkan NIS atau potongan nama, tidak case-sensitive.

Edit data

Ubah sebagian field saja — kolom yang dikosongkan tetap memakai nilai lama.

Hapus data

Ada konfirmasi sebelum data benar-benar dihapus, jadi tidak terhapus tak sengaja.

Rekap per kelas

Hitung jumlah siswa per kelas/jurusan, lalu ekspor rekapnya ke CSV atau TXT.

Cara menjalankan

Butuh Python 3, tidak ada library tambahan.

Unduh filenya

Klik tombol unduh di atas, atau clone repository ini ke komputer kamu.

Buka terminal di folder tersebut

Pastikan Python 3 sudah terpasang di komputer kamu.

Jalankan programnya

Ketik perintah berikut, lalu ikuti menu yang muncul.

python manajemen_siswa.py

Data tersimpan otomatis

Setiap perubahan langsung ditulis ke data_siswa.json di folder yang sama, jadi data tidak hilang saat program ditutup.

Aplikasi CLI manajemen siswa — dibuat dengan Python standard library.
